# Prompt Iteration Log

| Version | Design | Evaluation focus |
|---|---|---|
| V1 — Baseline | Subjects, exam dates, preparation levels, available hours; simple table | Relevance and readability |
| V2 — Improved | Adds urgency, difficulty, weak subjects, revision, practice, breaks, and constraints | Time cap, exam ordering, revision coverage |
| V3 — Integrated | Structured validation, planning workflow, output schema, and quality checks | Completeness, feasibility, clarity |

## Feedback incorporated
A senior student suggested giving more time to approaching exams and difficult subjects, including revision and breaks, and keeping the plan within daily available time.

## Evaluation protocol
Run the same inputs against V1, V2, and V3. Save outputs, score priority relevance, time-limit compliance, exam-date correctness, revision/practice inclusion, and clarity. Record failures; do not claim one version is better without results.
